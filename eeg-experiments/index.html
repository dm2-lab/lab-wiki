    Running EEG Experiments

    This page describes standard procedures for running EEG experiments in the DM² Lab.

    All experimenters are expected to follow these guidelines to ensure data quality, participant safety, and consistency across studies.

    The procedures below apply to typical EEG experiments involving decision-making tasks and behavioural responses.

    Overview of a Standard EEG Session

    A standard EEG session consists of the following stages:

    1. Preparation before the participant arrives
    2. Participant briefing and consent
    3. EEG cap fitting and electrode preparation
    4. Training block
    5. Main experiment (multiple blocks)
    6. Breaks and monitoring during the session
    7. Session completion and data saving

    At the end of each session, make sure to clean all EEG equipment, turn off the system, and place the battery on charge before leaving the lab.

    Electrode Preparation

    • Fill syringes with conductive gel
    • Prepare small pieces of tape for securing external electrodes
    • Attach round adhesive stickers to external electrodes
    • Prepare alcohol swabs

    Check Paperwork

    • Prepare the participant information sheet
    • Prepare the consent form
    • Confirm the participant ID

    EEG Preparation and Cap Fitting

    • Ask the participant to take a seat
    • Explain that an EEG cap will be fitted to measure brain activity
    • Explain that additional electrodes will be placed externally near the eyes and on the earlobes

    Purpose of External Electrodes

    • Eye activity generates strong electrical signals
    • These signals are recorded to help remove eye-related artefacts during analysis

    Key Points to Emphasize

    • The procedure is non-invasive
    • The participant may stop or ask questions at any time
    • Participant comfort is a priority

    Training Block

    Training can usually be conducted while electrode preparation is ongoing.

    • After attaching the external electrodes, allow the participant to start the training block
    • Launch the training task on the stimulation computer
    • Enter participant details as required
    • Read out task instructions in a conversational manner and ensure the participant understands the task

    Main Experiment

    Upon completion of the training block, instructions for the main experiment will appear.

    • Read out instructions in a conversational manner
    • Encourage questions and clarify any misunderstandings
    • Briefly summarise the key task requirements

    Starting Each Block

    When ready to start a block:

    • Confirm that the participant is comfortable and ready
    • Leave the EEG recording chamber and close the door
    • Start the EEG recording and enter the subject number using a consistent naming convention
      (e.g. Sub001_Block1)
    • Click Pause to begin EEG recording
    • Start the first block of trials on the stimulation computer

    Save EEG recordings separately for each block.

    During Each Block

    • Monitor incoming EEG data and participant performance
    • Observe response accuracy and behavioural patterns

    If responses suggest a misunderstanding:

    • Allow the participant to complete the current block
    • Clarify instructions before the next block begins

    Between Blocks

    • Stop the EEG recording
    • Save the data file using the correct naming convention
    • Check in with the participant:
    • How are you doing?
    • Do you need a short break or some water?
    • Do you have any questions?

    • Are you managing to blink during the slider periods?

    • Start the next block when the participant is ready

    Repeat this procedure for each block.

    Session Completion

    After the final block:

    • Stop and save the EEG recording
    • Confirm that all data files are saved correctly
    • Remove the EEG cap and electrodes
    • Clean all equipment according to lab procedures
    • Thank the participant for their time

    General Notes

    • Maintain a calm and professional tone throughout the session
    • Document any deviations from standard procedures
    • Record technical issues or unusual events
    • Ensure that all data are securely backed up after the session
